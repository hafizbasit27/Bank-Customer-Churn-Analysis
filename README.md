Bank Customer Churn Analysis 🏦
Project Overview
This project aims to identify and analyze the key factors contributing to customer attrition (churn) within a banking institution. By analyzing a dataset of 10,000 customers, the project provides data-driven insights to help the bank improve customer retention strategies.

Key Objectives
Data Cleaning: Preprocessing raw datasets to ensure high accuracy in analysis.

Exploratory Data Analysis (EDA): Investigating customer demographics, account information, and behavioral patterns.

Identifying Churn Drivers: Pinpointing the specific variables (e.g., age, balance, geography) that most impact a customer's decision to leave the bank.

Dataset
You can access the dataset used for this analysis here:

🔗 [https://www.kaggle.com/datasets/santoshd3/bank-customers]

Tools & Technologies Used
Python: Core programming language for analysis.

Pandas: Used for extensive data manipulation and cleaning.

Matplotlib & Seaborn: Used for generating statistical visualizations and correlation matrices.

Jupyter Notebook: Environment used for step-by-step code execution and documentation.

Key Insights & Findings
High-Risk Segments: Identified specific demographic peaks and geographic regions with significantly higher churn rates.

Retention Strategies: Delivered actionable recommendations to stabilize high-value account balances and improve overall customer loyalty.
